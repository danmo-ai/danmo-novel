# 林岸

`status`: canon
`role`: protagonist
`tagline`: 只把海底的东西原样带上来

## 三锚点

- 视觉：右手虎口一道旧疤，常年戴一块不防水的表
- 语言：短句，先给结论再给原因，不解释情绪
- 行为：下水前一定把记录仪擦一遍，再检查气瓶

## 欲望与底线

- 欲望：把沉在海底的事实原样带上来
- 底线：不把同伴推出去顶名额，也不替雇主改记录
- 伤口：十年前一次救援失败，他在水下听见了敲击声，最后没找到人

## 知识边界

- 知道：船体结构、焊口、潮汐
- 不知道：华光号当年真正载了什么
- 不知道自己被谁盯上

## 台词样例

- 压力下：先记，再动。
- 日常：图纸给我。
- 掩饰：随便看看。

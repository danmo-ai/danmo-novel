# Book bible — 雾港夜航

## Reader promise

- Genre / channel: 悬疑 / 近海打捞
- 看什么: 每一章给出一件能被验证的物证；读者比主角早半步看懂它的用途
- 爽点循环: 下水 → 摸到不对劲 → 按规矩记录 → 记录里出现一个不该存在的细节 → 岸上的人开始紧张
- 差异化: 不写灵异。所有"不对劲"最后都能落到一份文件、一次潮汐记录、一个被改过的值班表上

## 作者意图

- 主角目标: 把沉在海底的事实原样带上来，不管它证明谁有罪
- 故事引擎: 打捞作业 → 物证 → 记忆冲突 → 下一次更深的作业
- 终点: 真相上岸，代价是他再也下不了水

## 反模式

- 不写主角突然开窍。他每次都靠记录和复盘推进
- 不写反派临时起意的暴力。压力来自程序、文件、天气和期限

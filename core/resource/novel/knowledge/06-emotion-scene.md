# 情绪与场景

读者追的是情绪曲线，不是事件清单。按章纲 `beats` 加载对应场景节。

## 场面契约

细纲每个 `scenes[]` 建议填三字段（`emotional_beat` / `reader_effect` / `subtext`；与 `must_land` 同级）。上下文会抽取场面节拍；写正文时优先消费已提供的节拍，不要脱离合同另造一套。

| 字段 | 写什么 | 示例 |
|------|--------|------|
| `emotional_beat` | 本场主情绪 **从 X→Y**（一句） | 镇定→羞怒 |
| `reader_effect` | 期望读者感受（一句） | 替主角窝火 |
| `subtext` | 表面在谈什么 \| 实际在争什么；无对白写「无」 | 谈身份证明 \| 争面子高低 |

与「代入六支柱」对齐：`reader_effect` 优先落在**情绪共鸣 / 认知共鸣 / 欲望与好奇**；`emotional_beat` 用场景/动作兑现，勿形容词直说；`subtext` 对齐下节「潜台词 ≥30%」。失败要疼（丢面子/关系/时间）。道德可暧昧——读者不必同意主角，但须部分认同其选择逻辑。

## 情绪定调

动笔前先定本章主情绪：爽 / 虐 / 慌 / 暖 / 悚 / 窘。多情绪可以，但要有主次。钩子选型跟主情绪走。

### 用场景烘托情绪（禁形容词直说）

把作者当导演：环境、动作、声光、道具配合，**少写「他很愤怒/难过」**。

| 差 | 好 |
|----|-----|
| 他好难过，哭了 | 蜷在床边，指缝漏抽噎；碎相框里的笑刺眼；泪洇开地毯上的小花 |
| 她很紧张 | 袖口里攥紧的手指；目光掠过；语气仍平 |

情绪词可以偶发，但**画面与动作须先到位**。七宗罪可作情绪素材：调高=负面驱动，调低=美德（傲慢→自信，嫉妒→好胜）——与情节设计。`subgenre=刑侦探案` 禁止「心里一凛 / 汗毛立起」等代办词，身体反应分级。

**勿默认微动作尾巴：** 情绪已成立时，不要机械追加「攥紧拳头 / 咬唇 / 指甲掐掌心」作固定后缀；只在带来后果（伤、失败、人物习惯）时留。情绪延迟半拍再给判断，比事件当场总结更有人味。

**贯穿物件：** 重要道具/句子在全书至少换三次含义（初见 → 误读 → 真意），与「回声/意象」钩同向；。
## 期待管理

- **承诺**：开篇或卷首暗示的爽点/谜底，要在可感知窗口内推进。
- **延迟**：延迟要加代价或新信息，不能空拖。
- **反转**：类型是信息 / 身份 / 立场 三选一写进节拍；时机放在释放前或钩子上。反转前每个关键细节应可回看成立（公平戏）；误导路径须在前文留过可检索的假因，禁止无铺垫变卦。

| 类型 | 读者误以为 | 实际是 |
|------|------------|--------|
| 信息 | 缺一块事实 | 事实一直在，解读错了 |
| 身份 | TA 是谁 | 标签翻转（须早埋气味） |
| 立场 | 敌/友固定 | 利益或信念改边 |

自检：回看前文，假因能否被检索到？收益结算给谁四问）？

## 代入（六支柱浓缩）

目标感受：**主角就是我；这事发生在我身上；这是真实世界。**

**画面先于文字：** 动笔前先在脑中过一遍场面，再写；优先视觉/听觉/嗅觉/触觉落地，再补判断。练法：把影视精彩镜头写成文字直到满意——细则见下「场景沉浸」。

| 支柱 | 做法 | 尺度 |
|------|------|------|
| **基础信息标签化** | 谁、什么样、在哪、正经历什么 | 开篇百十字内可想象；一句话可带多信息 |
| **具体化 / 可视化** | 写读者能脑补的物件与场面，禁空泛「很美」 | 熟悉场景（高考后小树林、急救室门口）天然加分 |
| **熟悉感** | 接地气的时间地点情节，拉近距离 | 白描写法可，不土 |
| **认知共鸣** | 主角选择与目标读者同频（「我也会这么选」） | 选择点 > 旁白说教 |
| **情绪共鸣** | 亲情/不公/受辱等强情绪开篇 | 弱势纽带易代入；装逼打脸靠剧情本身，少混谈 |
| **欲望与好奇** | 具体欲望 + 具体障碍；信息差 | 见下条 |

- 具体欲望 + 具体障碍 > 空洞「很努力」。
- 让读者比配角多知道一点或少知道一点（信息差）。
- 失败要疼：损失资源、面子、关系或时间。
- 不认同角色 → 沉浸失败；先让读者**认知并部分认同**主角，再堆设定。

## 场景沉浸（五感与动线）

场景标签（`scene:establish` / `scene:transition`）或 beats 含 **建立场景 / 转场 / 环境** 时加载本节。目标：读者 **身在其中**，不是看作者列标签。

### 场景 = 连续时空里的转折动作

一个合格场景至少让人物处境发生**不可逆小变化**（价值情境转折）。开篇场景尤甚：用一系列动作显露人设与冲突层面，而非静物展览。人物 / 背景（时间·地点·冲突层面）/ 场景 三要素。

### 五感分层（勿全齐）

每个场景 beat **主 1 辅 1** 即可：

| 感官 | 用法 | 禁 |
|------|------|----|
| 视觉 | 1–2 个 **具体** 物件/光影（锚点），非「很美」 | 形容词堆叠 |
| 听觉 | 1 个环境声 + 1 个人声/动作声 | 连续无声段 >800 字 |
| 触觉/温度 | 与情绪同向（冷=压迫，热=窒息） | 与情节无关的通感装饰 |
| 嗅觉/味觉 | 仅当 **剧情相关**（毒、血、药、食物谈判） | 每场景强行「闻到」 |

**选细节原则：** 选 **可操作、可回访** 的物件（门闩、杯沿裂纹、湿掉的袖口），便于后文回声/意象钩。悬疑专有的感官钩。

### 动线与 blocking

写前先定 **三点**：

1. **入场点**：谁从哪进、面向谁
2. **冲突点**：空间中心（桌、门、台）；谁占上风占哪一侧
3. **出口**：本章场景结束时谁在哪、门是否关、道具在谁手

**规则：**

- 角色移动用 **动作** 写（「他退到柱后」），少用「在脑海中浮现布局图」式解说。
- 同时在场 ≤5 人时，每 2–3 段对白或动作点一次 **位置**（防「隔空对话」）。
- 打斗/追逐：环境 **参与**（窄巷、湿阶、断栏），非背景板。
- **时间锁 / 空间锁**（倒计时、封闭场所）与道德挑战叠用，紧张感倍增；悬疑向的用法。

### 氛围 vs 压迫

| 类型 | 写法 | 适用 |
|------|------|------|
| 氛围 | 1 个感官锚点 + 1 个社会细节（规矩/禁忌/目光） | 日常、情感、过渡 |
| 压迫 | 限制条件同场（出不去、不能说、时限、监视） | 悬疑、灵异、谈判、困境 |

氛围靠 **具体限制** 立住，不靠「气氛凝重」「空气凝固」。日常场景突然异常（反差）比纯阴森描写更刺——。

### 场景切换（过渡拍）

切换场景时 **至少一拍**，三选一：

- **时间拍**：「半刻后」「雨停时」
- **动作拍**：关门、上车、过门槛——用动作切断
- **感官拍**：光/声/温度突变，点明已换场

禁止硬切：「与此同时」「镜头一转」；禁止无说明 POV/地点跳变。

### 场景写得空的信号

首个 beat 只用 1 个锚点 + 入场动线立住；若读者说不出一「谁在哪、正被什么逼着做选择」，就按末尾「卡文诊断与场景救援」处理。

## 对话场景

- **效用测试**：每句对话须 推进情节 / 揭示人物 / 制造冲突 至少其一，否则删。
- **潜台词 ≥30%**：表面话题 ≠ 真实诉求；每章对话至少三成有言外之意。
- **遮名测试**：遮掉人名通读，能听出谁在说——不能则拉开句长/用词/回避点差异。
- **动作节拍**：用动作/神态节拍替代对话标签（「他道」「她说」连发 = 缺陷）；**有意义才加**，非句句堆砌。
- **信息控制**：先定「谁已经知道什么」；对白只放出章纲 `info_control.reveals` 允许的部分。
- **节制**：连续 5 轮无新信息 → 砍或换动作。
- **解释型对白判定**：角色把作者注释说给另一个已知情的人听（「你知道的，我们宗门有三禁……」）→ 删，改成行动或对不知情者施压。

## 打斗 / 对决

1. **态势**：谁占上风、环境约束
2. **交换**：2–3 个有代价的攻防
3. **转折**：规则/道具/心理破点
4. **落点**：胜负或僵局 + 身体/资源代价

禁止：纯招式名堆砌、无代价秒杀、战力突然跳档无铺垫。

围观分层：路人震惊 < 懂行的人改口 < 高层报价/站队。熟人震惊远爽于群演起哄。打脸围观释放链。

## 系统流 / 面板

- 面板信息 **≤3 行关键数据**；其余进内心或后续章。
- 系统说话要有 **人格或机械感二选一**，勿混。
- 奖励即时但 **代价同步**（冷却、任务、暴露风险）。

## 卡文诊断与场景救援

卡文不是「必须写更多字」的信号。先分清是「不知道接下来发生什么」还是「知道事件但写不出场面」。

**五种根因**

| 根因 | 症状 | 首选动作 |
|------|------|----------|
| 目标断了 | 主角没有当前想要的东西，只等事件发生 | 重写单元欲望与短期目标 |
| 冲突失效 | 障碍一碰就倒，或所有人都只配合主角 | 给对手独立目标、资源与反制 |
| 因果断了 | 下一章只能靠巧合或新设定继续 | 回到上一个选择，找它的代价与后果 |
| 信息失衡 | 该揭不揭，或底牌提前打光 | 重排揭示范围与伏笔节奏 |
| 场景无戏 | 事件有了，但人物只站着说明 | 从动作、利益碰撞与动线进入 |

当前单元已经写完、只是不舍得收：结算并挂下一钩，不要硬加一场。

**四步诊断**

1. 缩成一句：谁为了什么，必须在此刻做什么，否则失去什么？写不出就回细纲。
2. 找最后的变化：上一个人物选择带来了什么不可逆结果？
3. 找反对者：谁最有理由阻止，他会采取哪个具体行动？
4. 找代价：主角即使赢，也必须放弃、暴露或承担什么？

四个答案连不上，扩写只会放大问题。

**场景救援的最小改动**（只改一项，别全推翻）

- 换进入点：从事故、谈判、错误已经发生后切入，删抵达与寒暄；
- 换压力：加时限、旁观者、权限限制、资源不足或关系成本；
- 换知情差：让一方误解一个真实事实，而不是让大家变笨；
- 换空间作用：门、距离、出口、物件真正影响选择；
- 换胜法：由正面碾压改为证据、交换、诱导、协作或承担代价；
- 提前结算：冲突已兑现就收束，不重复同一轮争吵。

**各场急救重点**

- 对话场：双方各有一句不说出口的诉求；删互相介绍背景，让每次回应改变条件、信任或风险。
- 打斗场：先确认态势、环境约束、两三次有代价的交换；不用招式名掩盖没有胜负逻辑。
- 调查场：每次行动必须得到新事实、排除一种解释或付出调查成本；只重复询问就合并材料或跳到矛盾证据。
- 感情场：让一个人作出只有这段关系才说得通的选择；甜度来自具体照顾、边界改变或信任风险，不来自旁白宣布心动。
- 过渡场：只保留必要的位移、状态变化与下一压力；没有新信息就一句带过。

**不该做的救援**

- 用新角色、新系统、新地图或新秘密强行续命；
- 让反派降智、路人集体起哄、主角突然觉醒未登记能力；
- 为字数加天气、梦境、回忆或长段设定说明；
- 反复重写同一段开头却不修改冲突。

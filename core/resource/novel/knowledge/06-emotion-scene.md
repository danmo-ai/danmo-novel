# 情绪与场景

读者追的是情绪曲线，不是事件清单。按章纲 `beats` 加载对应场景节。

## 场面契约

细纲每个 `scenes[]` 建议填三字段（与 `must_land` 同级）；上下文会抽取场面节拍，写正文时优先消费已提供的节拍。

| 字段 | 写什么 | 示例 |
|------|--------|------|
| `emotional_beat` | 本场主情绪从 X→Y（一句） | 镇定→羞怒 |
| `reader_effect` | 期望读者感受（一句） | 替主角窝火 |
| `subtext` | 表面在谈什么 / 实际在争什么；无对白写「无」 | 谈身份证明 / 争面子高低 |

须与「代入六支柱」对齐：`reader_effect` 优先落在情绪共鸣、认知共鸣、欲望与好奇；`emotional_beat` 用场景与动作兑现；`subtext` 对齐「潜台词 ≥30%」。失败要疼（丢面子/关系/时间）。道德可暧昧——读者不必同意主角，但须部分认同其选择逻辑。

## 情绪定调

动笔前先定本章主情绪：爽 / 虐 / 慌 / 暖 / 悚 / 窘。可以多情绪，但要有主次；钩子选型跟主情绪走（见「爽点与追读」）。

**用场景烘托，禁形容词直说。** 把作者当导演，环境、动作、声光、道具配合。

| 差 | 好 |
|----|-----|
| 他好难过，哭了 | 蜷在床边，指缝漏抽噎；碎相框里的笑刺眼；泪洇开地毯上的小花 |
| 她很紧张 | 袖口里攥紧的手指；目光掠过；语气仍平 |

情绪词可以偶发，但画面与动作须先到位。**勿默认微动作尾巴**：情绪已成立时不要机械追加「攥紧拳头/咬唇/指甲掐掌心」，只在带来后果时留。情绪延迟半拍再给判断，比事件当场总结更有人味。

**贯穿物件**：重要道具或句子在全书至少换三次含义（初见 → 误读 → 真意）。

## 期待管理

**承诺**：开篇或卷首暗示的爽点/谜底，要在可感知窗口内推进。**延迟**：要加代价或新信息，不能空拖。**反转**：类型三选一（信息——读者以为缺一块事实，其实事实一直在、只是解读错了；身份——标签翻转，须早埋气味；立场——利益或信念改边），时机放在释放前或钩子上；反转前关键细节须可回看成立，误导路径须在前文留过可检索的假因。

## 代入六支柱

目标感受：主角就是我；这事发生在我身上；这是真实世界。动笔前先在脑中过一遍场面再写，优先视觉/听觉/嗅觉/触觉落地，再补判断。

| 支柱 | 做法 |
|------|------|
| 基础信息标签化 | 谁、什么样、在哪、正经历什么；开篇百十字内可想象 |
| 具体化/可视化 | 写读者能脑补的物件与场面，禁空泛「很美」；熟悉场景天然加分 |
| 熟悉感 | 接地气的时间地点情节；白描写法可，不土 |
| 认知共鸣 | 主角选择与目标读者同频；选择点 > 旁白说教 |
| 情绪共鸣 | 亲情/不公/受辱等强情绪开篇；弱势纽带易代入 |
| 欲望与好奇 | 具体欲望 + 具体障碍 + 信息差；让读者比配角多知或少知一点 |

失败要疼：损失资源、面子、关系或时间。不认同角色则沉浸失败——先让读者认知并部分认同主角，再堆设定。

## 场景沉浸

场景标签（`scene:establish` / `scene:transition`）或 beats 含建立场景、转场、环境时加载本节。一个合格场景至少让人物处境发生不可逆小变化；开篇场景尤甚——用动作显露人设与冲突，而非静物展览。

**五感分层（主 1 辅 1，勿全齐）**：视觉给 1–2 个具体物件或光影（禁形容词堆叠）；听觉给 1 个环境声 + 1 个人声/动作声（禁连续无声段 >800 字）；触觉/温度与情绪同向（冷=压迫，热=窒息）；嗅觉/味觉仅当剧情相关（毒、血、药、食物谈判）。选可操作、可回访的物件（门闩、杯沿裂纹、湿掉的袖口）。

**动线**：写前先定入场点（谁从哪进、面向谁）、冲突点（空间中心在桌/门/台；谁占上风占哪一侧）、出口（结束时谁在哪、门是否关、道具在谁手）。角色移动用动作写；同时在场 ≤5 人时每 2–3 段点一次位置；打斗/追逐让环境参与；时间锁/空间锁与道德挑战叠用。

**氛围 vs 压迫**：氛围 = 1 个感官锚点 + 1 个社会细节（规矩/禁忌/目光），用于日常、情感、过渡；压迫 = 限制条件同场（出不去、不能说、时限、监视），用于悬疑、灵异、谈判、困境。氛围靠具体限制立住，不靠「气氛凝重」。日常场景突然出现一处不该有的东西，比整段阴森描写更刺。

**场景切换**至少一拍：时间拍（「半刻后」「雨停时」）、动作拍（关门、上车、过门槛）、感官拍（光/声/温度突变）。禁止硬切「与此同时」「镜头一转」；禁止无说明的 POV 或地点跳变。

若读者说不出「谁在哪、正被什么逼着做选择」，按末尾「卡文诊断」处理。

## 对话场景

- **效用测试**：每句须推进情节 / 揭示人物 / 制造冲突至少其一，否则删。
- **潜台词 ≥30%**：表面话题 ≠ 真实诉求。
- **遮名测试**：遮掉人名能听出谁在说。
- **动作节拍**：用动作或神态替代对话标签，有意义才加。
- **信息控制**：先定「谁已经知道什么」，对白只放出 `info_control.reveals` 允许的部分。
- **节制**：连续 5 轮无新信息 → 砍或换动作。
- **解释型对白**：角色把作者注释说给已知情的人听 → 删，改成行动或对不知情者施压。

## 打斗 / 对决

态势（谁占上风、环境约束）→ 2–3 个有代价的攻防 → 转折（规则/道具/心理破点）→ 落点（胜负或僵局 + 身体/资源代价）。禁止纯招式名堆砌、无代价秒杀、战力突然跳档无铺垫。

围观分层：路人震惊 < 懂行的人改口 < 高层报价/站队；熟人震惊远爽于群演起哄。

## 系统流 / 面板

面板信息 ≤3 行关键数据，其余进内心或后续章。系统说话人格或机械感二选一，勿混。奖励即时，代价同步（冷却、任务、暴露风险）。

## 卡文诊断与场景救援

卡文不是「必须写更多字」的信号，先分清是不知道接下来发生什么，还是知道事件但写不出场面。

| 根因 | 症状 | 首选动作 |
|------|------|----------|
| 目标断了 | 主角没有当前想要的东西 | 重写单元欲望与短期目标 |
| 冲突失效 | 障碍一碰就倒，所有人只配合主角 | 给对手独立目标、资源与反制 |
| 因果断了 | 下一章只能靠巧合或新设定继续 | 回到上一个选择，找它的代价与后果 |
| 信息失衡 | 该揭不揭，或底牌提前打光 | 重排揭示范围与伏笔节奏 |
| 场景无戏 | 事件有了，人物只站着说明 | 从动作、利益碰撞与动线进入 |

单元已写完只是不舍得收：结算并挂下一钩，不要硬加一场。

**四步诊断**：缩成一句（谁为了什么，必须在此刻做什么，否则失去什么）→ 找最后的变化 → 找反对者（谁最有理由阻止，会采取哪个具体行动）→ 找代价（即使赢，也必须放弃、暴露或承担什么）。四个答案连不上，扩写只会放大问题。

**场景救援（只改一项）**：换进入点（从事故、谈判、错误已发生后切入）／换压力（时限、旁观者、权限、资源、关系成本）／换知情差（让一方误解一个真实事实）／换空间作用（门、距离、出口真影响选择）／换胜法（由碾压改为证据、交换、诱导、协作或承担代价）／提前结算。

**各场急救**：对话场——双方各有一句不说出口的诉求，每次回应改变条件、信任或风险；打斗场——先确认态势与交换，不用招式名掩盖胜负逻辑；调查场——每次行动必须得到新事实、排除一种解释或付出调查成本；感情场——让一个人作出只有这段关系才说得通的选择；过渡场——只留必要的位移与下一压力。

**不该做的救援**：用新角色、新系统、新地图或新秘密强行续命；让反派降智、路人集体起哄、主角突然觉醒未登记能力；为字数加天气、梦境、回忆或长段设定说明；反复重写同一段开头却不修改冲突。

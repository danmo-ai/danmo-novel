# 卡文诊断与场景救援

卡文不是必须续写更多字的信号。先判断是「不知道接下来发生什么」，还是「知道事件但写不出场面」，再选对应工具。

## 一、五种常见根因

| 根因 | 症状 | 首选动作 |
|------|------|----------|
| 目标断了 | 主角没有当前想要的东西，只等事件发生 | 重写单元欲望与短期目标 |
| 冲突失效 | 障碍一碰就倒，或所有人都只配合主角 | 给对手独立目标、资源与反制 |
| 因果断了 | 下一章只能靠巧合或新设定继续 | 回到上一个选择，找它的代价与后果 |
| 信息失衡 | 该揭不揭，或底牌提前打光 | 重排揭示范围与伏笔节奏 |
| 场景无戏 | 事件有了，但人物只站着说明 | 改从动作、利益碰撞与动线进入 |

还有一种常见情况：当前单元已经写完，只是作者不舍得收。此时应结算并挂下一钩，而不是硬加一场。

## 二、四步诊断

1. **缩成一句**：谁为了什么，必须在此刻做什么，否则失去什么？写不出就回细纲。
2. **找最后的变化**：上一个人物选择带来了什么不可逆结果？下一场从结果长出来。
3. **找反对者**：谁最有理由阻止这件事，他会采取哪个具体行动？
4. **找代价**：主角即使赢，也必须放弃、暴露或承担什么？

四个答案能连起来，再写场面；连不起来，扩写只会放大问题。

## 三、场景救援的最小改动

保留事件目标，优先改下列一项，不要全部推翻：

- **换进入点**：从事故、谈判、错误已经发生后切入，删掉抵达与寒暄；
- **换压力**：加时限、旁观者、权限限制、资源不足或关系成本；
- **换知情差**：让一方误解一个真实事实，而不是让大家突然变笨；
- **换空间作用**：门、距离、出口、物件真正影响选择与结果；
- **换胜法**：由正面碾压改为证据、交换、诱导、协作或承担代价；
- **提前结算**：当前冲突已经兑现就收束，不重复同一轮争吵。

## 四、各场景的急救重点

### 对话场

双方各有一句不直接说出口的诉求。删掉互相介绍背景的对白，让每次回应改变条件、信任或风险。

### 打斗 / 对抗场

先确认态势、环境约束、两三次有代价的交换与转折。不要用更多招式名掩盖没有胜负逻辑。

### 调查场

每次行动必须得到新事实、排除一种解释或付出调查成本。若只是重复询问，合并材料或跳到矛盾证据。

### 感情场

让一个人作出只有这段关系才说得通的选择。甜度来自具体照顾、边界改变或信任风险，不来自旁白宣布心动。

### 过渡场

只保留必要的位移、状态变化与下一压力。若没有新信息或关系变化，用一句过渡而非完整一场。

## 五、不该做的救援

- 用新角色、新系统、新地图或新秘密强行续命；
- 让反派降智、路人集体起哄、主角突然觉醒未登记能力；
- 为字数加入天气、梦境、回忆或长段设定说明；
- 反复重写同一段开头，却不修改冲突；
- 一次勾选所有知识文章，让模型自己寻找方向。

## Checklist

- [ ] 已区分结构卡文与表达卡文
- [ ] 当前目标、反对行动、选择与代价能连成因果
- [ ] 只选最小必要改动，不推翻已成立内容
- [ ] 救援后产生新状态，而不是原地加时
- [ ] 若单元已完成，已及时结算并留下具体下一钩

# 节奏与结构

长篇连载靠节奏留人：开篇抓人、章中推进、章末留钩。钩子类型见「爽点与追读」，本文只管节奏与结构怎么排。

## 黄金开篇（前三章）

前 500 字必须落地气味：

1. **冲突先于设定**：直接进入利益冲突或悬念，少说明书。
2. **读者承诺清晰**：这本看爽、看虐、看悬疑？第一章就要兑现气味。
3. **主角能动**：主动选择 > 被动挨打后长解说。
4. **信息分层**：世界观用行动带出，不堆名词表。

**禁项：** 世界观说明书、名词表点名、被动挨打后长解说、套题材公式当章法。

**6 种禁用开头（每章通用）：** 天气开场、日常作息流水账、上章内容回顾、慢速背景铺垫、寒暄对话、设定讲座。

**前 20% 规则：** 每章前 1/5 篇幅内必须出现冲突或压力源；前 3 段内读者能看到本章的戏剧问题。

### 三跳点（首章）

| 跳点 | 位置 | 必须有什么 | 禁止 |
|------|------|-----------|------|
| 第一跳 | 前 300–500 字 | 主角身份可辨 + 一个具体冲突或异常气味 | 天气、日常、背景铺垫 |
| 第二跳 | 前 1500–2000 字 | 金手指/核心设定第一次在动作里显现 | 设定讲座 |
| 第三跳 | 章末 | 一个具体钩子 | 感悟式结尾 |

### 露一藏九与中途切入

只露约一成信息（冲突现场、异常气味、半句身份），其余随行动再交；从激烈冲突或利益对撞的半场写起，用信息差制造好奇；开篇抛的钩不要当章拆光。

开篇顺序（可删不可乱）：情节钩子 → 陷入异常 → 金手指气味 → 欲望/矛盾运转 → 本卷目标立住。

### 黄金三章逐章交付

ch1 交冲突在场、主角能动、题材气味、具体钩，读者离场要能回答「这人是谁、在什么麻烦里、这类书什么味」。ch2 抬 stakes，给小代价或小胜利，读者要知道「比上一章更糟/更难/更近了什么」。ch3 给一个完整释放闭环（压抑→蓄势→释放→余韵），让读者看见「这类书主要看主角用什么方式推进」。

ch1 前 300 字（番茄向 hard）：主角身份可辨 + 利益/生命/关系冲突 + 金手指或核心异常气味同场或紧接。ch3 不必卷级高潮，但须可命名（章纲 `pleasure_point` 非空且正文兑现）。跨章冲突形态应变化，禁止三章同一打脸模板。

## 章内节奏

单章 {{chapter_chars_min}}–{{chapter_chars_max}} 字，内部也要有波动，不能平推到底、章末才钩。

| 段 | 约占章 | 任务 | 读者感受 |
|----|--------|------|----------|
| 入场 | 0–15% | 接钩或立场景；谁在哪、要什么 | 立刻知道这一章从哪开始 |
| 加压 | 15–70% | 障碍递增、信息差、关系位移 | 比章首更紧 |
| 小释放/反转 | 70–90% | 小胜/小败/半揭/代价落地 | 情绪有一个落点 |
| 章末钩 | 90–100% | 未完成动作或新 stakes | 想翻页 |

蓄势章可把「小释放」换成显性代价，但仍须有落点。

**300–500 字波动**：任意连续 300–500 字内至少出现一项——新信息、新压力、关系位移、感官/场景切换。禁止同一情绪强度下纯描写堆叠 >500 字；禁止同一解释型对白 >3 轮无新信息。

**铺垫密度**

| 章类型 | 写法 | 章纲标记 |
|--------|------|----------|
| 推进章 | 每 300–500 字波动；章内至少 1 次小释放 | 默认 |
| 蓄势章 | 可延迟大释放，但每 800–1000 字须有微推进；章末钩仍须具体 | `purpose` 含「蓄势章」 |
| 纯铺垫章 | 禁止连续 3 章（`PacingDensity` blocking）；两章蓄势后下一章必须可命名释放 | — |

蓄势不是「什么都不发生」，而是大释放延后 + 微推进不断。

**段长与屏效（番茄向）**：单段 ≤3 行，一屏 3–5 段；长段独白 >5 行拆段或改动作。动作场景一句 ≈15 字以内，对话一句一段。场景转换用空行或过渡拍，禁止单独一行 `---`（只用于章与章之间）。

**章节标题**：写本章关键事件/悬念，带具体物件、动作或数字；不写「暗流/抉择/初遇」。

## 五步锁卷

锁卷纲前按此顺序，禁止从章纲倒推卷目标：**定高潮**（本卷最大冲突与最强情绪，先写高潮再填前面）→ **切剧情单元**（每单元 = 一段章 3–8 章，一次矛盾从起到收；卷纲以结构化单元实体锁 unit_id、章范围、目标、阻碍、尝试、方法缺口、选择、代价、不可逆结果、状态迁移、前置原因、揭示边界与下一钩；逐章场面进 `outline/units/*.yaml`；相邻单元换金手指用法或冲突形态，单元之间必须有因果）→ **预埋信息点**（地图/阵营/人物/金手指/规则/矛盾/收集/感情，只标「何时露面」）→ **定开篇舞台**（切口 + 期待）→ **定收尾**（主线落地、奖励可见、节奏放缓、下一卷钩子，不打光终局底牌）。

## 节点与八节点

起始（谁/处境/能力，越糟越好写）→ 节点（2–4 个跨多章成长点，不偏离终末）→ 终末（卷终必须得到或失去什么）。流派 = 主角从起始走到终末的手段。

| 节点 | 任务 | 约占卷 | 节奏 |
|------|------|--------|------|
| 开篇 | 抓住读者，建立期待 | 5–10% | 快 |
| 发展 | 递进事件 + 埋伏笔 | 30–40% | 中 |
| 中点/转折一 | 打破预期，改格局 | 5–10% | 快 |
| 加压/转折二 | 赌注升级，类型与上一转不同 | 5–10% | 快 |
| 高潮 | 核心冲突正面对决 | 10–15% | 极快 |
| 余波 | 战利品可见，喘息 | 10–15% | 慢 |
| 转折三（可选） | 颠覆「已经结束」的预判，须有铺垫 | 5–10% | 快 |
| 收束 | 情感落地，留白；勿回收全部伏笔 | 10–15% | 慢 |

爽文小循环（套在单元内）：稳定 → 危机 → 破局 → 结算 → 新平衡 + 预埋。

## 卷与章

- **卷纲**：一卷一个升级目标 + 一次主高潮，只写单元索引（章范围 + 一句话功能 + 禁碰）。
- **剧情单元**（3–8 章）是创作最小单位。细纲 yaml 写欲望/阻碍/节拍/场面序列与章切口；正文是一份 `units/vNN-U#.md`。
- **章**是这份正文里的切口（`## 第N章`，章间单独一行 `---`），不是独立故事。爽点、主钩、状态增量写在单元上各一次；中间章只要 `cut_hook`。场面 `must_land` 落地后章末只切断，单元末才收主爽点。

## 主线句与节奏点

动笔前先能说完一句：**谁 + 在什么困境 + 为了什么目标 + 必须对抗什么 + 最终获得或失去什么**。说不清就不要开写。

起段（约前一成到一成半）只负责钩住：主角、处境、最初矛盾、一个还想往下看的问题。中段反复「目标 → 阻碍 → 代价 → 收获 → 新问题」。高潮分档放：证明自己、把圈子做大、首次惨胜或惨败、推进转折。不要每章都高潮。

**黄金节奏点**（按单元预设）：每个区间四件套——阶段目标、主爽点、小危机、读者还在等什么。单章只承担这个区间里的一场。

## 矛盾链与五项驱动

欲望 + 阻碍 = 矛盾。一个矛盾收束后立刻埋下一个（或抬高同一矛盾的 stakes）。浅矛盾可单章收，深矛盾占一个剧情单元。中期疲软的常见病是主线散架、矛盾断链、纯升级流水账；自救顺序：复盘卷纲单元索引与细纲 → 加快进度精简注水段 → 换地图或支线 → 拆配角线。卡文阶段禁止水文凑字。

双线（如事业 + 感情）各有自己的欲望–阻碍链，交织点写进 yaml 的 entry/choice；禁止两线各自平推，禁止感情线空降抢走已承诺的主爽点。

每 3–5 章扫一次五项驱动：压力来源是否具体？解题方式是否有新意？哪个认知被打破？资源/地位是否可见增值？解决后引出什么新疑问？同类套路间隔 ≥3 个不同形态单元。

## 字数与扩写

字数不达标是症状不是病，先判类型：

| 判断 | 处理 |
|------|------|
| 赶、薄、欠戏剧化 | 扩写（每章 ≤3 种技术，首稿后另开一轮） |
| 紧、快、完整但短 | 调整 `chapter_chars`（仍须在 {{chapter_chars_min}}–{{chapter_chars_max}} 内），不注水 |
| 结构缺 beats | 先改纲，扩写只会放大问题 |

**七种技术**：场景细节充实 / 内心独白 / 对话扩写（潜台词谈判）/ 感官层次（主导感官 + 2–3 其他）/ 副线编织 / 节奏调制（关键时刻 1 段拉 3–5 段）/ 氛围构建（环境作情绪镜像）。

**纪律**：每章最多 3 种；删掉不弱化章节 = 注水；扩写段落仍须有张力；背景倾倒、设定讲座、总结叙述不算扩写；玄幻仙侠忌扩写打斗，推理忌独白泄密，恐怖忌副线破氛围；扩写后重跑本地检查；卡文不是扩写时机。

## AI 扩写前置

单元细纲须已写清：本章目的、不可逆事件、`pleasure_point`（或明确蓄势）、`hook.out`。开篇钩子优先人写定调（冲突切口 + 一句悬念），再让模型填感官与过渡。字段未满就续写 = 批量注水。

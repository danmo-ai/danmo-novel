# 人物与群像落笔

人设设计在「人设设计」篇。本文只管写进正文时怎么让人物活起来、怎么不崩。

## 出场方法（首出场定生死）

**有效四种**：行动中出场 / 冲突中出场 / 矛盾中出场（言行不一）/ 他人眼中出场（借第三方评价）。**动态优先于静态**：声 → 在场者反应 → 入场动作 → 再点容貌，比从头到脚的外貌目录更难忘。

**禁用四种**：照镜子自描、简历式罗列设定、起床日常开场、无语境的外貌目录。

## 气质三锚点（防 OOC）

每个反复出场的角色锁定三个可观察锚，章内至少兑现 1 个：

| 锚 | 写什么 | 崩了的样子 |
|----|--------|------------|
| 视觉 | 标志外貌、物件、姿态 | 换脸换装无交代 |
| 语言 | 口头禅、回避点、句子长短 | 全员同一腔调 |
| 行为 | 压力下的习惯动作 | 性格标签与临场选择相反 |

三锚点是「读者认人」的钩子，四件套是「角色为什么行动」。不要用「气场强大」代替视觉锚；一个特征动作胜过通篇形容词。

**语言习惯 vs 性格标签**：「冷淡」「热情」「毒舌」是标签，照这个写出来还是同一腔调。语言习惯要写成可照着写的东西：对谁说话用什么语域、口头禅（≤2）、一碰就转开的话题、句子是短促还是绕弯。另留三条台词样例（压力/日常/掩饰，各 ≤40 字），只写台词，不在后面解释性格。

| 反例 | 症状 | 修法 |
|------|------|------|
| 全员同一腔调 | 遮掉人名分不清谁在说 | 每人口头禅和信息密度至少一项不同 |
| 语域不随对象变 | 对上级和对朋友一个口气 | 分三行：对上 / 对平 / 独处 |
| 样例后面解释 | 「……这说明他其实很脆弱」 | 删解释，脆弱靠下一句台词写出来 |

## 活人感四法

| 法 | 做法 | 禁 |
|----|------|----|
| 填过往 | 回忆/伏笔穿插解释动机，一点一点放 | 一次性倒完；与性格剧情无关的回忆 |
| 加细节 | 动作、微表情、袖口攥紧的手指 > 「他很生气」 | 每句对白都堆动作 |
| 添成长 | 困境 → 挣扎 → 改变 → 沉淀 | 无理由一蹴而就 |
| 赋配角灵魂 | 配角有目标/烦恼/短支线，可与主线交织 | 工具人反复横跳；作用结束仍占戏 |

成长可分：主角主线成长 / 配角辅助成长 / 反派反向成长（非洗白，是动机更复杂）。

## 配角非工具人

- **删除测试**：删掉这个配角故事就崩，才配留下；删掉无影响 → 合并或删。
- 每个重要配角有独立小目标，与主角目标相交而非附属；出场带态度（如何看主角，会否改变）。
- 同功能角色合并；死亡与退场的后果须与角色分量成正比——不为震惊值杀人。
- 写配角时暂时当主角写；反派和反复出场的配角要有自己要保的人和事。小反派被解决后若他的关系网还会找上门，这条线才算活。

| 功能 | 作用 | 例 |
|------|------|----|
| Confidant 心腹 | 让主角说出内心 | Watson |
| Foil 对照 | 反衬主角选择 | Draco |
| Catalyst 催化 | 触发事件后让位 | 报信人 |
| Mirror 镜像 | 主角的另一条人生路径 | — |
| Stakes anchor 代价锚 | 让读者在乎输赢 | 家人/徒弟 |
| Comic relief 缓冲 | 调节节奏，不破氛围 | — |

## 群像与关系网

非 POV 重要角色连续出场 ≤3 章，之后须轮换或给新信息增量。同屏角色宁少勿多；新角色入场须有功能名分。刑侦探案里配角各有一件「过不去的事」。

用关系变化推进剧情：信任增减、秘密共享、债务与恩情；章纲 `state_deltas` 写关系进/出。**关系三要素**（缺一不可）：不对称（双方想要的东西不同）+ 张力源（利益/秘密/权力差）+ 必须演变（静态关系禁止）。

感情线的四阶段与 CP 设计见「人设设计」；正文里每一次推进都要落在一个可见选择上。

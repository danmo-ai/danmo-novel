# 人物与群像落笔

人设设计在「人设设计」篇。本文只管**写进正文**时怎么让人物活起来、怎么不崩。

## 出场方法（首出场定生死）

**有效四种**：行动中出场 / 冲突中出场 / 矛盾中出场（言行不一）/ 他人眼中出场（借第三方评价）。

**动态描写优先于静态**：声 → 在场者反应 → 入场簇拥/动作 → 再点容貌（王熙凤式），比从头到脚外貌目录更难忘。

**禁用四种**：照镜子自描、简历式罗列设定、起床日常开场、无语境的外貌目录。

## 气质三锚点（防 OOC / 漂移）

每个反复出场的角色锁定三个可观察锚，章内至少兑现 1 个：

| 锚 | 写什么 | 崩了的样子 |
|----|--------|------------|
| 视觉 | 标志外貌、物件、姿态 | 换脸换装无交代 |
| 语言 | 口头禅、回避点、句子长短 | 全员同一腔调 |
| 行为 | 压力下的习惯动作 | 性格标签与临场选择相反 |

三锚点是「读者认人」的钩子，四件套是「角色为什么行动」。不要用「气场强大」代替视觉锚。一个特征动作胜过通篇形容词。

### 语言习惯 vs 性格标签

「冷淡」「热情」「毒舌」是性格标签，照这个写出来还是同一腔调。语言习惯要写成**可照着写**的东西：对谁说话用什么语域、口头禅（≤2）、一碰就转开的话题、句子是短促还是绕弯。另留三条台词样例（压力 / 日常 / 掩饰，各 ≤40 字），只写台词，不在后面解释性格。

| 反例 | 症状 | 修法 |
|------|------|------|
| 全员同一腔调 | 遮掉人名分不清谁在说 | 每人口头禅和信息密度至少一项不同 |
| 语域不随对象变 | 对上级和对朋友一个口气 | 分三行：对上 / 对平 / 独处 |
| 样例后面解释 | 「……这说明他其实很脆弱」 | 删解释；脆弱靠下一句台词写出来 |

## 活人感四法

| 法 | 做法 | 禁 |
|----|------|----|
| **填过往** | 回忆/伏笔穿插解释动机；一点一点放 | 一次性倒完；与性格/剧情无关的回忆 |
| **加细节** | 动作、微表情、袖口攥紧的手指 > 「他很生气」 | 每句对白都堆动作 |
| **添成长** | 困境 → 挣扎 → 改变 → 沉淀；可贴遗憾 | 无理由一蹴而就；懦弱瞬间无所畏惧 |
| **赋配角灵魂** | 配角有目标/烦恼/短支线，可与主线交织 | 少数工具人反复横跳；作用结束仍占戏 |

成长可分：主角主线成长 / 配角辅助成长 / 反派反向成长（非洗白，是动机更复杂：嫉妒→放手、仇恨→悲情）。

## 配角非工具人

- **删除测试**：把这个配角删掉，故事就崩——才配留下；删掉无影响 → 合并或删。
- 每个重要配角有独立小目标，与主角目标相交而非附属。
- 出场带「态度」：如何看主角，会否改变。
- 工具型龙套可扁平；反复出场者需增量信息。
- 同功能角色合并；死亡与退场的后果须与角色分量成正比——不为震惊值杀人，为故事价值杀人。
- 写配角时**暂时当主角写**：出身、处境、他会如何应对——才鲜活。
- **千人一面**：同一口气、同一欲望、同一受压反应。分开靠欲望、口吻和压力下的习惯动作，不靠多堆形容词。遮掉人名仍分不清谁在说话，就是没分开。
- **反派和反复出场的配角要有自己要保的人和事。** 小反派被解决后，若他的关系网还会找上门，这条线才算活。删掉无影响的人不要留着凑人数。

### 配角功能六型（一个角色可兼）

| 功能 | 作用 | 例 |
|------|------|-----|
| Confidant 心腹 | 让主角说出内心 | Watson |
| Foil 对照 | 反衬主角选择 | Draco |
| Catalyst 催化 | 触发事件后让位 | 报信人 |
| Mirror 镜像 | 主角的另一条人生路径 | — |
| Stakes anchor 代价锚 | 让读者在乎输赢 | 家人/徒弟 |
| Comic relief 缓冲 | 调节节奏，不破氛围 | — |

## 群像轮换

- 非 POV 重要角色连续出场 ≤3 章，之后须轮换或给新信息增量。
- 同屏角色宁少勿多；新角色入场须有功能名分。
- `subgenre=刑侦探案` 时配角各有一件「过不去的事」。

## 感情线落笔

四阶段勿跳级：相识气味 → 试探/错位 → 临界 → 确认或永失。每阶段至少一个**可见选择**。

- 女频：关系推进是主引擎，每次都推进关系节点。
- 男频：感情是战果或代价，不抢主爽点循环。
- 禁忌：旁白宣布「他们相爱了」；跳过临界直接确认。

## 关系网演进

用关系变化推进剧情：信任增减、秘密共享、债务与恩情。章纲 `state_deltas` 写关系进/出。

**关系三要素**（缺一不可）：不对称（双方想要的东西不同）+ 张力源（利益/秘密/权力差）+ 必须演变（静态关系禁止）。

## 知识边界（防 OOC）

POV 角色只能写其可知信息。隐藏设定不得从主角嘴中「刚好猜中」除非章纲允许。

配角不能像读过人物卡一样理解主角——只写他根据公开行为能形成的判断。

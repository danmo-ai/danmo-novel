# 人设设计

角色是欲望与伤口的载体，不是标签拼盘。人设靠**剧情碰撞中的选择**立住，小传写完 ≠ 立住。

**情节爽不如人设爽**：同题材好看与否，差在人物关系拉扯。人设上的天然冲突感（立场/三观/利益）> 单纯堆事件。

**三禁（设计期就要防）：**

| 禁 | 症状 | 修法 |
|----|------|------|
| **纸片人**（主角） | 无欲望/无变化/只会挨打或开挂 | 四件套 + 弧光；每章至少一个可见选择 |
| **工具人**（配角） | 只为主角递刀递话，删了故事仍转 | 独立小目标；删除测试 |
| **背景板**（世界/龙套） | 设定与群演不参与冲突 | 环境参与动作；龙套有态度或合并删 |

## 欲望–阻碍–矛盾

主人公**想要什么**（欲望）而**得不到**（阻碍）→ **矛盾**。矛盾推动剧情；深度决定篇幅。一个矛盾收束后马上埋下一个。

卡文时用动机链：起因（具体事件）→ 意图 → 约束 → 失败代价。禁止「被欺负」这类空话。

## 角色功能分工

| 角色 | 优先 | 含义 | 禁 |
|------|------|------|----|
| 主角 | **功能性 > 完美性** | 身上有别人做不到的事（金手指、信息差、独特手段）；不完美才生剧情 | 开局全能无缺口 |
| 配角 | **记忆点 > 完整性** | 抓 1 个独特锚点（嗜甜暗卫、结巴毒医）；描写少，防抢戏 | 配角简历式铺满 |
| 反派 | **破坏力 > 邪恶值** | 必须实际施压（修为/权势/情报）；菜鸡再坏也不是反派 | 只骂不伤、降智送赢 |

## 主角四件套

人物卡落在 `canon/cast/<stem>.md`，第一行是「# 纯姓名」，再写 `tagline`、`role` 与 `status`。

1. **欲望**：此刻要什么（可观察）
2. **伤口**：为何怕失去 / 为何偏执
3. **手段**：惯用解题方式（智/力/情/骗）
4. **代价底线**：绝不做或一定会做的事（=「不妥协点」；写到极致才有记忆）

**速填表格**：每出一个重要角色至少记 姓名 · 年龄跨度 · 明暗身份 · **动态外貌习惯**（禁静态目录）· **记忆锚点**（疤/口头禅/配饰）· 家庭背景气味 · 情感联系（亲/友/恋各 1 条即可）。背景越复杂，可延伸剧情越多；身份过简 → 剧情易平。

## 矛盾与弧光

- **矛盾**是区分「人物」与「原型」的关键：同一角色身上必须存在两处真实张力——「战场上勇敢，爱情里怯懦」「最恨谎言，却靠谎言谋生」。没有矛盾的角色只是功能。
- **弧光**三态：起点 → 当前 → 预期终点（含**拒绝改变**的反向弧——别人成长，他守住/崩于原念）。弧光靠选择推进，不靠旁白宣布。
- **偏差许可制**：行为偏离四件套当且仅当（被戏剧化为成长时刻 / 外力逼迫 / 同章或下一章被点明）。忘记设定、剧情强扭人物、无戏内解释 → OOC。

### 性格：单一强化

长篇人物多，读者记不住「既善良又勇敢又聪明又雷厉风行」。**配角与卷对手：性格单一并反复强化**（莽就莽到底）。多重性格留给篇幅够长的主角；除非巨大变故，勿章间性格翻转。

性格须符合成长环境与身份；**思想核心 = 追求**——不断设障阻止其追求，人物才活。

### 反差标签法

外表标签 × 内里标签，表面可反差，底层须自洽：

| 层 | 写什么 | 例 |
|----|--------|-----|
| 身份 | 明面 vs 暗面 | 面馆老板 / 风水师 |
| 性格 | 浓缩标签，靠事件兑现 | 清冷 × 嘴毒；柔弱 × 扛事 |
| 价值态度 | 积极/消极甚至自相矛盾 | 厌世却仍救人 |

习惯、喜恶、口头禅是记忆点，也是后文伏笔锚（怕猫 → 被设局；嗜鸡 → 玩世不恭标签）。

## 人物取名反 AI

名字是第一道出戏感。AI 味常见不是「起错字」，而是**同一审美批量出厂**：高频姓 + 文艺双字 + 全员同构。

### 先定再取（缺一项先别起名）

1. **时代 / 地域 / 阶层**（九零派出所 ≠ 仙门内门 ≠ 一线互联网公司）
2. **家庭命名逻辑**（辈分字、父母文化、小名/绰号是否入文）
3. **已用名表**（同批角色字数、声韵、字形至少一项可区分）

### P0 — 禁止

| 禁 | 例（模式，非穷尽） | 修法 |
|----|-------------------|------|
| 全员冷峻文艺双字同构 | 凌寒/凌霜/凌月；夜辰/墨染/清欢同批堆 | 拉开字数与字义方向；混入日常名/带辈分名 |
| 同批高度相似 | 萧炎+萧寒+萧尘同场 | 换姓或换尾字；声母韵母至少错开 |
| 现代文复姓堆砌 | 慕容/上官/欧阳全员 | 现代默认单姓；复姓须有设定理由 |
| 寓意说明书 | 善人名「正明德」、恶人名「邪暗魔」 | 名与命运弱相关；人味靠行为 |
| 生僻字炫技 | 一字需查字典才能念 | 换常用字；方言可留口耳名 |
| 正文临时发明正式姓名 | 章纲未点名、cast 无卡却突然全名登场 | 先 `candidate` 卡；龙套用工称/绰号 |

**高频 AI 尾字慎用（同批 ≤1 个角色带下列字）：** 晚、清、深、辞、言、染、寒、霜、夜、墨、玄、凌、澈、笙、妄。

### 题材气味

| 题材 | 推荐 | 反例 |
|------|------|------|
| 都市 | 常见名 + 身份绰号（老周、张科） | 全员古风雅名、复姓仙气 |
| 刑侦 / 探案 | 同上 | 同上 |
| 玄幻 | 双/三音节可古，但不全员一个味 | 同姓三连、全员「凌X」 |
| 仙侠 | 俗名 + 道号双轨更稳 | 全员道号且风格雷同 |
| 古言 / 现言 | 日常化，区分阶层与年代感 | 全员三字冷感网文名 |

### 龙套纪律

- **有功能无名分** → 「门卫老刘」「值班法医」即可，不配完整姓名。
- 需要回访的龙套 → 绰号或姓+称谓先立住，升格再给全名并补 `candidate`。
- 同章新出名有姓角色 ≤3（主角已在场外）；超了先合并或改工称。

### 自检

- [ ] 说得出时代/阶层依据
- [ ] 与已用名在字数/声韵/字形上可区分
- [ ] 非说明书寓意；非同批文艺尾字扎堆
- [ ] 重要角色已有/将有 cast 卡；龙套未强行全名

## 反派层级

按出场篇幅选层，禁止「小反派当全书 Boss 写」或「大 Boss 降智送赢」。

| 层级 | 篇幅 | 必有 |
|------|------|------|
| 小反派 | 1–5 章 | 1–2 个鲜明特征，干脆退场 |
| 卷对手 | 约 10–30 章 | 动机说得通；至少赢主角一次 |
| 大弧 Boss | 一卷或数卷 | 理念冲突 + 绝境战 + 失败余波 |
| 最终 Boss | 全书 | 第一章就有气味；代表主题反面 |

建立顺序：实力展示 → 动机可信 → 真实威胁 → 真意图留到反转。反派智商决定主角含金量。

### 动机光谱

| 类型 | 内核 | 备注 |
|------|------|------|
| 理念型 | 自洽世界观，认为自己在行善 | 最引人注目，首选 |
| 创伤型 | 伤口驱动，以伤害回应伤害 | 与主角镜像时最强 |
| 系统型 | 体制/规则本身作恶，人是齿轮 | 适合群像与社会派 |
| 镜像型 | 主角的反面教材「若主角走岔」 | 张力天然 |
| 虚无型 | 无动机之恶 | 最难写，慎用 |

最好的反派认为自己是自己故事的主角：有独立于主角的欲望与恐惧、能胜任的威胁、与主角的私人关联。`subgenre=刑侦探案` 时，困境写到数字、来路写圆。

## 感情线与 CP（有则填）

四阶段，勿跳级：相识气味 → 试探/错位 → 临界（信任或决裂）→ 确认或永失。每阶段至少一个**可见选择**，禁止旁白宣布「他们相爱了」。

男频极简：感情是战果或代价，不抢主爽点循环。女频：关系推进本身就是主引擎。

**CP 当整体设计**，再填单人卡：

| 要素 | 做什么 | 缺了会怎样 |
|------|--------|------------|
| **天然冲突** | 三观、立场、社会身份、伦理、阶级至少占 1–2 维 | 糖写不长或硬凑 |
| **致命吸引** | 学识/性情/经历互补等，忌纯血药强绑 | 感情干、莫名其妙在一起 |

CP 类型：一见钟情 / 日久生情 / 由恨生爱 / 步步为营。关系：单暗 / 双暗 / 明恋 / 一爱一恨 / 被迫绑定。
副 CP、男配女配线用不同「类型×关系」组合，防同质。

## 卡的完整度按 role

`protagonist` / `volume_antagonist` 填满四件套、矛盾弧光、知识边界、三锚点、语言习惯、三条台词；主角另填金手指段。
`recurring` 只要欲望、与主角相交点、功能六型选一、一条锚、口头禅、一条台词。
龙套不建卡。

正文上下文按 `on_stage` 精简注入，其余留在卡上。

## 群像预算（开书登记）

- **同屏角色宁少勿多**；新角色入场须有功能名分。
- 开书用表记录人设，防重叠与遗忘（群像百万字以上尤甚）。
- 关系网每对都要有张力源；禁止静态关系——每对关系必须演变。

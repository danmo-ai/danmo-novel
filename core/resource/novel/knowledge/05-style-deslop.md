# 文风与去 AI 味

文风是可复用资产：先锁定，再写章。定稿必须像人写的连载。
「AI 味」的本质不是用错词，而是**没有脉搏**：无观点、无混乱、无具体、无不确定。

本文管**写作时**怎么写出人味。三类内容分工：

| 类别 | 文件 | 谁执行 |
|------|------|--------|
| 程序规则 | `core/resource/novel/gates/deslop_rules.yaml`（不在知识库） | 引擎正则，永不进提示词 |
| 默认注入 | `25-review-checklist`（`default: true`） | 每次审校自动带上 |
| 用户选择 | 知识库里其余文章 | 作者在运行确认窗口勾选 |

本文属于**第三类**：只在写作/设定重写时可选，**不参与审校**。
文风判断维度已并入 `25-review-checklist` 第六节，密度阈值在程序规则里；
在审校时勾选本文只会稀释模型注意力——别这么做。

## 视角与画面

- **有限第三人称**（网文常见）：贴主角感知，利于悬念。
- **第一人称**：声音强，但知情人边界更严——不得知道他人想法。
- 一章内不乱切上帝视角；多 POV 需在章纲标明；全知视角换头必须有场景分隔；时态切换每章 ≤1 次。
- 优先：动作、对话、感官细节 → 再补判断。少用抽象总结句。

## 对话指纹

- 每人有口头禅/回避点/信息密度差异；遮掉人名也能听出是谁（遮名测试）。
- 对话推进利益或揭示性格；删除纯复述已知信息的对白；解释型对白（"as you know, Bob"）是缺陷。
- **人名也是指纹：** 模板文艺名扎堆 = 出戏。取名纪律。

## 通顺（写包固定约束；非禁词表）

短句可以。气接不上常见于：一个意思拆成三四段、下一句不接上一句的结果、同一动词紧挨着说两遍。

- 一个意思写成一句完整的话，不要拆成三四段。
- 下一句接上一句的结果。
- 同一动词不在相邻两句里各说一遍。
- 连续四句以上、每句没有新信息 → 删。
- 上一句里已经出现的话，不得再单独成段。

## 文风分层（可记入 project memory）

| 倾向 | 特征 | 适合 |
|------|------|------|
| 热血爽文 | 短句、快切、释放密 | 玄幻升级 |
| 都市烟火 | 生活细节、对白自然 | 都市/职场 |
| 古风意境 | 留白、比兴、战写意 | 仙侠古言 |
| 悬疑压抑 | 信息克制、环境压迫 | 悬疑灵异 |
| 刑侦人味 | 动作顶替情绪、数字顶替形容词；闲笔与物象 | 刑侦/探案（深描 →「刑侦人味文风」） |

## 量化指标在哪查

不在本文。文风里「数得出来」的部分（破折号密度、禁词命中、翻案腔、程度词…）由**程序规则**判定，
每次审校自动跑并把结果写进 findings——你不需要、也不应该凭记忆去数，更不要声称执行了本文没有的检测。

判断维度与判定权限（`25-review-checklist.md`）第六节。

## 写作时自检（判断维度，非阈值表）

写正文时对照这几条，**不要**去数字数或数破折号——那是程序规则的事。

| 症状 | 改法 |
|------|------|
| 喊情绪（「他感到无比愤怒」） | 分级生理动作：轻度 咬牙/吞咽；中度 手抖/声音破；重度 砸拳/腿软 |
| 感悟式章末（「或许，这只是个开始」） | 收在具体未决事件上 |
| 上帝视角剧透 POV 不知的事 | 只写他能看见、能推断的 |
| 装饰符号癖（过量 emoji、【震惊】） | 全删，层次靠文字 |
| 语域乱跳（古风章突然现代鸡汤） | 先定语域，全文统一 |
| 客服腔 / markdown 泄漏进正文 | 整段删 |
| 代词开头句连发（他…他…他…） | 换主语或合并 |
| 全员同一腔调 | 遮名测试：听不出谁在说就重写 |
| 解释型对白 | 删掉互相讲解读者已知的段落 |

## 勿过度去 AI（硬约束）

实测证明下列特征**不是**可靠 AI 指纹，润色时不得单凭它们改稿（改编自 lieflat 白名单边界；小说语境另注）：

| 特征 | 为什么不改 |
|------|-----------|
| 句长/段长不够参差 | 与人类写作无稳定差别；禁止为「制造节奏」拆段调句 |
| 补虚词（就/很/了） | 方向对但无法验收，正式叙述容易被改成口语 |
| 被动句、名词化、长句本身 | 现代汉语书面常态；只处理上面列出的五种叙述层翻译腔 |
| 正文「首先…其次」 | 与人类无差别；程序规则只数密度，不禁止 |
| 句内同构排比、比喻本身 | 人类不比 AI 少；小说有意排比/比喻按文风指纹保留 |
| 问句、设问 | 删掉更不像人写 |
| 材料稀薄就「补细节」 | 违反信息守恒：润色不得新增姓名/数字/因果/心理；抽象就让它抽象，或退回扩写轮 |

**冲突优先级：** `canon/style-fingerprint.md`（本书指纹）> 程序规则判定的 blocking > 本文建议。指纹允许的破折号密度、口头禅、排比，不得被通用去 AI 规则删掉。

## 解药：写出脉搏

1. **要有观点**——叙述者对人事有态度，不中立播报。
2. **放进杂乱**——允许离题半句、半生不熟的念头、没说出口的话。
3. **要具体**——「横断左眉的疤」而非「英俊」；具体物件、具体数字。
4. **变化节奏**——句长、段长、信息密度高低交替。
5. **承认复杂**——不确定和矛盾是特性，不是要抹平的瑕疵。
6. **情绪用身体写**——用分级生理动作替代抽象情绪命名。

## 叙事架构

读者觉得「像情节推进机器」时，问题在架构不在词频。完整对照表在「审校规则」第七节；
写作时只需要记住一句：**用选择和代价演示主题，别用旁白解释主题。**

## 文字减法与出戏感

**减法：** 删同义复读、空总结、不推动冲突的对白与描写。每段问「删了故事会怎样」——不会 → 删。卡文时尤忌用注水顶字数（见扩写纪律与「卡文诊断与场景救援」）。

**出戏感（沉浸失败）：** 语域乱跳、人设腔调漂移、说明书对白、上帝视角剧透、节奏突兀（该紧偏松/该松硬吼）都会把读者拽出故事。自检：遮掉人名后对白是否仍像同一个人？场景转换是否有过渡拍？情绪写这个人做了什么，不写「他痛苦绝望」五个字。

## 操作顺序

1. 先看叙事架构（上节），每单元最多挑 3–5 处动，别全条拉满
2. 跑本地检查，读 findings：先修 blocking，再处理 advisory
3. 删套话与空总结，改「告诉」为「展示」
4. 拉开角色对白差异，章末钩子改成具体未决事件
5. 复查 blocking 清零；别把 advisory 照单全收

## 刑侦加严（advisory）

仅 `subgenre=刑侦探案`：可再压破折号（目标 ≤2/千字）与单句打点，并禁情绪代办词——细则第十二节。比喻 / tic / 「不是 X 而是 Y」仍以本文建议与实际审校结果为准。定稿 blocking 不因人味加严项单独 FAIL。

## 番茄向加严（advisory）

番茄读者更下沉、更快读，对 AI 味和文绉绉更敏感。默认阈值之上再压：

| 项 | 默认 | 番茄向目标 |
|----|------|-----------|
| 破折号「——」 | 程序规则 ≤5/千字 | 向 ≤3/千字靠 |
| 四字格 / 成语 | 人工判断 | 能拆成大白话就拆（"怒不可遏"→"把杯子掼了"） |
| 形容词堆叠 | 段级 advisory | 优先动作/物件，少用"美丽/庄严/深邃" |
| 长句 | 不硬检 | 番茄向单句尽量 ≤20 字；短句可以，但一个意思写成一句完整的话，不要拆成三四段 |
| 对白单调 | 人工判断 | 连续 ≥6 段纯对白无动作打断、同一「X说。」连发 ≥4 次 → advisory |

这一档是 advisory，不单独 blocking；但番茄向读者读完率敏感，宁可压狠一点。详见 `20-tomato-launch.md`。

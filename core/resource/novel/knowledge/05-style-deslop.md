# 文风与去 AI 味

文风是可复用资产：先锁定，再写章。定稿必须像人写的连载。

「AI 味」的本质不是用错词，而是没有脉搏：无观点、无混乱、无具体、无不确定。

## 三类内容分工

| 类别 | 位置 | 谁执行 |
|------|------|--------|
| 程序规则 | `core/resource/novel/gates/deslop_rules.yaml`（不在知识库） | 引擎正则，永不进提示词 |
| 默认注入 | 审校规则（`default: true`） | 每次审校自动带上 |
| 用户选择 | 知识库其余文章 | 作者在运行确认窗口勾选 |

本文属于第三类：只在写作/设定重写时可选，不参与审校。文风里「数得出来」的部分（破折号密度、禁词命中、翻案腔、程度词）由程序规则判定并自动写进 findings——写作时不要凭记忆去数，也不要声称执行了不存在的检测。

## 视角与画面

- 有限第三人称（网文常见）：贴主角感知，利于悬念。
- 第一人称：声音强，但边界更严——不得知道他人想法。
- 一章内不乱切上帝视角；多 POV 须在章纲标明；全知换头须有场景分隔；时态切换每章 ≤1 次。
- 优先动作、对话、感官细节，再补判断；少用抽象总结句。

## 对话指纹

每人有口头禅、回避点、信息密度的差异，遮掉人名也能听出是谁。对话推进利益或揭示性格；删纯复述已知信息的对白；解释型对白是缺陷。人名也是指纹：模板文艺名扎堆就是出戏（取名纪律见「人设设计」）。

## 通顺（写包固定约束，非禁词表）

- 一个意思写成一句完整的话，不要拆成三四段。
- 下一句接上一句的结果。
- 同一动词不在相邻两句里各说一遍。
- 连续四句以上、每句没有新信息 → 删。
- 上一句里已经出现的话，不得再单独成段。

## 文风分层（可记入 project memory）

| 倾向 | 特征 | 适合 |
|------|------|------|
| 热血爽文 | 短句、快切、释放密 | 玄幻升级 |
| 都市烟火 | 生活细节、对白自然 | 都市/职场 |
| 古风意境 | 留白、比兴、战写意 | 仙侠古言 |
| 悬疑压抑 | 信息克制、环境压迫 | 悬疑灵异 |
| 刑侦人味 | 动作顶替情绪、数字顶替形容词 | 刑侦探案（细则见「刑侦人味文风」） |

## 写作时自检（判断维度，非阈值表）

| 症状 | 改法 |
|------|------|
| 喊情绪（「他感到无比愤怒」） | 分级生理动作：轻 咬牙/吞咽；中 手抖/声音破；重 砸拳/腿软 |
| 感悟式章末 | 收在具体未决事件上 |
| 上帝视角剧透 POV 不知的事 | 只写他能看见、能推断的 |
| 装饰符号癖（emoji、【震惊】） | 全删，层次靠文字 |
| 语域乱跳（古风章突然现代鸡汤） | 先定语域，全文统一 |
| 客服腔 / markdown 泄漏进正文 | 整段删 |
| 代词开头句连发（他…他…他…） | 换主语或合并 |
| 全员同一腔调 / 解释型对白 | 遮名测试；删互相讲解已知信息 |

## 勿过度去 AI（硬约束）

下列特征不是可靠 AI 指纹，润色时不得单凭它们改稿：

| 特征 | 为什么不改 |
|------|-----------|
| 句长/段长不够参差 | 与人类写作无稳定差别；禁止为「制造节奏」拆段调句 |
| 补虚词（就/很/了） | 方向对但无法验收，正式叙述容易被改成口语 |
| 被动句、名词化、长句本身 | 现代汉语书面常态 |
| 正文「首先…其次」 | 与人类无差别；程序规则只数密度，不禁止 |
| 句内同构排比、比喻本身 | 人类不比 AI 少；有意排比/比喻按文风指纹保留 |
| 问句、设问 | 删掉更不像人写 |
| 材料稀薄就「补细节」 | 违反信息守恒：润色不得新增姓名/数字/因果/心理 |

**冲突优先级：** `canon/style-fingerprint.md`（本书指纹）> 程序规则判定的 blocking > 本文建议。指纹允许的破折号密度、口头禅、排比，不得被通用去 AI 规则删掉。

## 解药：写出脉搏

要有观点（叙述者对人事有态度，不中立播报）；放进杂乱（允许离题半句、没说出口的话）；要具体（「横断左眉的疤」而非「英俊」）；变化节奏（句长、段长、信息密度交替）；承认复杂（不确定和矛盾是特性）；情绪用身体写。

**减法**：删同义复读、空总结、不推动冲突的对白与描写。每段问「删了故事会怎样」——不会 → 删。卡文时尤忌注水顶字数。

**出戏感**来自语域乱跳、人设腔调漂移、说明书对白、上帝视角剧透、节奏突兀。自检：遮掉人名后对白是否仍像同一个人？场景转换是否有过渡拍？情绪写这个人做了什么，不写「他痛苦绝望」五个字。叙事架构层面的问题（主题靠旁白解释、因果过干净、道德全白全黑）见「审校规则」——写作时只记一句：用选择和代价演示主题。

**操作顺序**：先看叙事架构，每单元最多挑 3–5 处动 → 跑本地检查，先修 blocking 再处理 advisory → 删套话空总结，拉开角色对白差异 → 复查 blocking 清零，别把 advisory 照单全收。

## 番茄向加严（advisory）

破折号向 ≤3/千字靠（程序规则 ≤5 才 blocking）；四字格能拆成大白话就拆；优先动作/物件，少用「美丽/庄严/深邃」；单句尽量 ≤20 字；连续 ≥6 段纯对白无动作打断、同一「X说。」≥4 次 → advisory。不单独 blocking，但番茄读者读完率敏感，宁可压狠一点。

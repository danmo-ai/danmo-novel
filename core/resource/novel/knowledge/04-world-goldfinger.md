# 世界观与金手指

设定是约束，不是词条展览。金手指是引擎，不是外挂无限子弹。

## 优先写清的四层

落盘 `canon/world.md`，金手指细则写 `canon/goldfinger.md`，不另起一套结构。

1. **力量/规则**：谁能做什么、代价是什么、上限在哪。
2. **势力地图**：谁占资源、冲突线在哪。
3. **日常物质**：钱、交通、通讯、阶级观感（烟火气）。
4. **禁忌与法律**：碰什么会死、会被追杀。

## 一致性与设定带出

新设定先查旧规则；冲突则走 **change request**，禁止静默改 canon。「例外」必须写代价，否则等于无规则。地图与时间线分开维护，跨城/跨日要可核对。

规则、地图、势力须在冲突里用到才出场：读者通过主角的选择与代价学会世界，而不是通过旁白讲座。开篇与换地图时尤忌名词表；露一藏九。用冲突逼出设定，少开会解说。

## 反流水账升级

每次升级/破境/换地图须服务剧情爽感或关系位移：打完有缴获、声望、新阻碍或信息。禁止纯堆等级数字、同构打怪循环。钱和阶级也一样——除非人物为它做了选择。

## 金手指卡片（必填）

| 字段 | 说明 |
|------|------|
| 名称与本质 | 它到底是什么能力 |
| 获得契机 | 为何是 TA |
| 代价 | 每次或累积付出什么 |
| 限制 | 冷却、次数、场合、不可用条件 |
| 成长方式 | 如何变强，是否可预期 |
| 近 5 次使用 | 防止遗忘与膨胀 |
| 代劳比例 | 解决冲突时金手指占比上限建议 |
| 新鲜度计划 | 下一次形态变化何时出现 |

**使用纪律**：本章靠金手指破局要在章纲写明，审校核对代价是否兑现；禁止「刚好有新功能」无登记（新功能 = change request → canon）；连续三章金手指主解冲突 → 强制插入非金手指解题或加重代价；不得代劳关键抉择与情感高潮（见「强约束」）。

## 平衡四问与战力防崩

自检四问：有代价或限制吗（冷却、次数、情绪触发、资源消耗）？服务主线还是抢戏（系统代抉择 = 抢戏）？有可复述的记忆点吗？弱起还是开局满配（满配须立刻加世界反压）？

要让读者感到「这手能赢」，同时必须有限制；没有限制，后面的情绪会塌。修炼档位少另起一套名词——要创新，改的是世界怎么运转、人怎么受这套规则的气。

敌人/地图/境界成**梯队**，禁止越级秒顶级。开书算一次：体系档数 × 每档停留篇幅 ≥ 全书目标字数，不够就加层。金手指、身份、社会地位四点要统一；触顶 = 动用终局底牌，须到解锁卷。

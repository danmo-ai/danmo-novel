# 强约束

每章动笔前和审稿时都要过一遍。读者契约与终局储备写在圣经/总纲里，本文只给判定标准。时间线与知情边界的细则见「连续性与信息控制」。

## 读者契约

开篇、题材、主角配置共同许诺的阅读快感。先问：读者是来看主角解决问题、看群像、看导师托举，还是看制度合作？契约不同，同一情节的风险不同。

**主角代理权 = 因果权 + 结算权**（不看出场时长，不要求事事亲手）：谁决定事情为什么发生、如何进入？谁作出不可替代的关键选择？谁承担或选择关键后果？核心收益、认可、权力结算给谁？

配角可执行局部动作，不得无声夺走已承诺的高光。核心资产（金手指、关键证据、身份底牌）不得无交换上交机构。

| 等级 | 定义 | 处理 |
|------|------|------|
| 契约安全 | 与开篇一致；选择与收益清楚 | 可写，交换须可见 |
| 需补强 | 稀释高光或推进过快，能用铺垫/代价修好 | 写前补理由或改成阶段性兑现 |
| 契约破坏 | 没收卖点；无关角色夺走期待所有权；无交换接管核心资产 | 修纲，不得定稿 |

## 期待债

每次承诺（会反击、会升级、会揭身份、会推进感情）都欠一笔债。可以延期，但要付利息：阶段性进展、新信息、局势变化或更清晰的下一目标。用设定解说拖延等于合理化债务。换地图、新机构、新能力、新敌人都新增期待债，不能靠新鲜感逃避旧承诺。

## 金手指代劳

金手指不得代劳主角的关键抉择与情感高潮；代劳比例建议 ≤30% 章内情节推动力。系统发任务 ≠ 主角无选择；每次使用记 `resources` 代价。违反 → review **StrongConstraints** blocking。

## 终局储备

圣经/总纲「终局储备」只写解锁卷号；真相细节只进 `canon/author-lore.md`。未到解锁卷：禁止揭开头号宿敌真身、打光金手指上限、或让升级线无下一档。卷纲「终局边界」与单元「禁止提前释放」是同一约束的卷/段落地。

**锁词**：本卷之前不得出现的真名/真相词登记在 `canon/locked-terms.yaml` 的 `locked_until`（按卷）+ `compliance`（永久红线）。写作上下文会注入当前卷的揭示约束；定稿前仍需核对正文。

**透支两问**（任一为「是」→ 回退改纲）：是否动用了本阶段还不该解锁的终局底牌？是否让某条升级线逼近天花板、后面没台阶接？两问皆否时，一战多得（破境 + 缴获 + 声望）允许；多线齐涨不算透支。

## 叙事线

同时活跃主线 + 支线 ≤3 条；新开线须有旧线收尾或降级为伏笔。章纲 `forbidden` 列出本章不得推进的线。

## 人机分工

人定灵魂，AI 填骨架与细节。不得整段交给模型代决：本书读者契约与终局台阶；本单元主冲突、关键对白、不可逆选择；伏笔开/进/关与期待债结算归属；定稿润色后的「像不像这本书」。

允许 AI：章纲细化、场面填充、设定整理、审稿扫雷。**禁止**把「以下是为您润色/优化后的内容」一类指令语留进正文。章纲关键字段（`pleasure_point` / `hook` / 欲望阻碍）未满时，不要让 AI 先扩正文。

## 写前阻断（每章动笔前）

答不出任一项 → 先改章纲，不准开写：本章不可逆事件或压力源是什么（前 300 字内须落到动作/对话）？谁结算本章收益，是否仍符合读者契约四问？金手指是否代劳了关键抉择？章末切口是具体事件还是口号？与上一章同场景连写时，是否换了冲突形态或信息增量？

叙述层禁止元话语（「卷一」「前文所述」「后文再表」「本章」）；章号只出现在 `## 第N章` 标题。

## 冲突禁话疗收束

单元/章标题或细纲承诺对抗、决战、对决时，禁止用「我理解你 / 共鸣唤醒 / 融合救赎 / 不是消灭是解放」几句话让对手自行崩解或倒戈，且主角零代价。允许谈判、策反、智取，但须有可见代价、行动步骤或未完成的对抗节拍。

## 高频雷点

| 雷 | 判定 | 处理 |
|----|------|------|
| 水文/注水 | 卡文或凑字时写无关痛痒段；删了故事更清楚 | blocking：砍段、加快进度 |
| 开篇信息过载 | ch1 堆世界观/履历/体系，无冲突无钩 | blocking（开篇期）；改露一藏九 |
| 无钩/口号钩 | 章末无可感知悬念或「故事才刚刚开始」 | 番茄向 ch1–3 blocking；其后 P0 文风 |
| 节奏混乱/冲突乏力 | 连续多章无加压、无微兑现、矛盾断链 | PacingDensity / ReaderPull；回改细纲 |
| 爽点不足 | 开篇单元没有主爽点；其后连续单元 `pleasure` 空 | 重排单元细纲 |
| 话疗破局 | 承诺对抗的章用纯说教收冲突且无代价 | 回改 |

## 发稿前自查

前后是否接得上（时间、伤势、已知信息、已收的坑）；有没有同义复读与删了不影响的段；错字、病句、人设口吻是否串了；中后期变水要回细纲，不要用改字假装修好。

```yaml
constraint_checks:
  goldfinger_ratio_ok: true   # 未代劳关键抉择
  timeline_monotonic: true
  active_plot_lines_le_3: true
  endgame_reserve_ok: true    # 透支两问皆否
  agency_settled: true        # 四问：收益回到承诺所有者
```

## 审核红线（全题材共用）

- 禁真实地名、政府机关、领导人名称；禁影射现实政治。
- 禁把封建迷信写成可操作的细教程；女频禁冥婚、结阴亲、怀鬼胎；男频禁冰恋。
- 血腥模糊化；禁屠城和反人类场面；禁借类型写色情。
- 正义须按走得通的规则落地；扫黑不能靠私刑或超自然代替。
- 平台在收紧低质 AI 稿（叙事不清、结构混乱、转折生硬、逻辑割裂、指令残留）的签约；去 AI 与人机分工是内部纪律，不替代各平台现行公告。

题材多出来的红线写在各题材篇。

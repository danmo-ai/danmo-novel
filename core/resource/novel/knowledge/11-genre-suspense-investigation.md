# 悬疑

用未知制造怀疑，再用公平的线索把怀疑解开。读者要的是「我也能推」，不是「作者说了算」。

三条硬纪律：线索在揭示前出现；侦探不得比读者早知道；每章必须推进线索或改变怀疑方向。

## 读者契约与子类

须有曲折、悬念、收得回的逻辑，不必全程吓人。

| 子类 | 读者来看 | 正文落到 | QC |
|------|----------|----------|-----|
| 推理探案 | 逻辑解谜、线索回收 | 严密推理；结局意外但说得通 | `mystery` |
| 刑侦探案 | 案件链、职业感、正义兑现 | 单元案串主线；证据能回看 | `mystery` |
| 灵异风水 | 猎奇、因果、氛围 | 从小案升级；超自然不能包打 | `mystery` |
| 男频悬疑爽 | 日常细节、信息差、反转 | 快接近真相时设障碍；善恶有报 | `male_power` + `mystery` |
| 女频悬疑 | 破案为主、感情为辅 | 一案一结，感情只进一小步 | `mystery` |

**人味文只跟「刑侦探案」**：警察、法医、查案过日子、动机带社会性，才写 `subgenre: 刑侦探案`。灵异写「悬疑灵异」，规则怪谈写「规则怪谈」，男频悬疑爽写「悬疑脑洞」，感情为辅的女频刑侦写「女频悬疑」。`mystery` 不是人味开关。

规则怪谈多，不等于正统悬疑；差异在信息公平、逻辑闭环、人物会变。

### 子类误挂速查

| 你实际在写 | 正确子类 | 不要 |
|------------|----------|------|
| 警察/法医过日子，公平线索破案 | `刑侦探案` | 通灵、见鬼、三炷香破局 |
| 命案皮 + 通灵/玄学破局 | `悬疑灵异`；系统碾压为主 → 系统穿越「悬疑副本」 | `刑侦探案` |
| 日常账单/监控/邻里信息差，无办案程序 | `悬疑脑洞` | 套刑侦七步 |
| 规则副本、假规则推理解谜为主 | `规则怪谈` | 系统直接报真凶；挂成刑侦探案 |
| 惊悚游戏/诡异复苏且金手指推副本 | 系统穿越「悬疑副本」；公平解谜为主仍改 `规则怪谈` | 刑侦程序 |
| 破案为主、感情每案只挪半步 | `女频悬疑` | 感情盖过破案；男主飘成完美神探 |

短篇课堂里的「破案刑侦 + 玄学」一律按第二行处理，不并入刑侦办案程序。

## 本题材的开篇切口

在「节奏与结构」的通用纪律上，悬疑再加：异常先于设定（禁专业术语课与世界观讲座）；只给现象或结果，不给前因；冲突要具体，有感情基础之前不用空泛的「被追杀」；第一页就有信息差，或离奇事件与限制条件同场；有名有姓的人不超过三四个，视角少跳。

用硬悬疑把人引进来，后文若改成纯爽而不再悬，弃书会高。刑侦探案的开篇形状：高能开头 → 写实中段 → 翻转结尾（天气只能参与发现尸体，不能当镜头）。

## 场景写法（悬疑专有）

**感官钩（可回访）**：固定重复的噩梦片段、只有主角闻得到的血腥味、某双眼睛像蛇。一个钩出现两次以上才算钩，第二次要比第一次多一点信息。

**视线压迫**：「总觉得背后有人，回头却空的」——用虚实交错的错觉加压，不写「诡异」「不祥」。

**时间锁/空间锁**：倒计时（天亮前、尸体腐败到某一步）或封闭场所（停电的楼、雪封的村、审讯室）。锁与道德挑战叠一起才紧：出不去，还得决定救谁；破锁手段要在前文可检索。

**环境即线索、反差**：封闭空间里的具体物（米缸、监控死角、门锁痕迹）要能进解谜；日常场景里突然出现一处不该有的东西（早餐桌上多一副碗筷、监控里多一个人影），比整段阴森描写更刺，只用具体物。灵异子类靠信息不对称与反差立氛围，不靠形容词；真相仍遵守已经写过的规则。

## 单元上的爽点形态

一个单元推进一条短线：接近真相 → 设障碍 → 揭开一层 → 长线前进一步。中间章只留信息缺口，不要为章末钩子改掉已经成立的逻辑。结构三选一，写进细纲而不是每章一个新故事：多案并行（主线在人物关系）／小案串大案／女频一案一结（感情只挪半步）。

悬疑额外好用的钩：读者和主角知道的不一样；查清一件事才能碰到更大的事；倒计时或没开的门；抓到人之后同手法再现（类型仍从「爽点与追读」的库里选）。

**男频悬疑爽**（`悬疑脑洞`）：日常账单、监控、邻里对话里长出三层钩——核心疑问、手法疑问、何时揭晓。主角多为被辜负的普通人或职场边缘人；每次只差一步时设合理障碍，配角的反应（偷笑、回避、多嘴）把情绪顶上去。情绪弧：前期「是否误会」→ 中期同情与愤怒同步升 → 后期揭晓与善恶有报。反派要有内在账，结局仍善恶有报。

| 变体 | 读者要看 | 正文落到 |
|------|----------|----------|
| 惊悚游戏 | 高死亡率副本、通关/反杀 | 副本惊悚与难度；金手指可助洞察，不能面板报真凶 |
| 规则怪谈 | 假规则、矛盾规则、推理解谜 | 信息公平；重在揭开副本规则 |
| 诡异复苏 | 人鬼两阵营、灵气与威胁同场 | 从小案升级；超自然不能包打真相 |
| 恐怖末世 | 阵营崩溃后的求生与先知优势 | 血腥仍模糊化；先知须贬值 |

**灵异与非刑侦单元**可用循环（不套刑侦七步）：危险降临 → 线索排查 → 再度遇险 → 深度排查。每轮排除一批疑点，逼近一层真相。禁「一切都是梦」；中期不要强行换地图；重要配角退场要推出新冲突。

## 刑侦办案程序（仅「刑侦探案」）

灵异、规则怪谈、悬疑脑洞不套这套步子；女频悬疑可压缩步数，感情仍只挪半步。正文质感见「刑侦人味文风」。

**单元案七步**：案发（现场有一处反常，先不讲前因）→ 排查（多人有秘密）→ 第一次锁定随即推翻 → 物证或时间线对不上 → 第二层嫌疑人浮出 → 逻辑闭合（真凶说得通，前文线索能回看）→ 收束时埋主线或旧案的下一步。

**审讯与对撞**：不一次招供——先承认小问题，再瞒关键，最后被一处细节击破；推翻旧判断时监控、行踪、证词、物证、时间线至少两样对得上；每案备 2–3 个假凶，各有动机、疑点与说得圆的嫌疑，最后全部推翻，理由前文已出现。

**三层悬念**：浅——这一案谁干的；中——动机为何不像情杀、仇杀、财杀；深——与连环、旧案或主线怎么连。反转落点优先是执念、旧怨、灭口掩盖旧案。真相从主角查到的材料里出来：不写凶手独立心理，不把答案提前交给读者；信息差可以有，揭开时线索必须公平回看。

**现场与章钩**：现场和尸检只写反常与特征（整洁或凌乱过了头、物品错位、出入路径对不上、死亡时间、致死原因、习惯痕迹），施暴过程与逃避追查的做法都不写。章末仍用「爽点与追读」的 `hook.type`，刑侦只指定切口：新物证推翻此前判断 → 突然揭示；不在场证明有漏洞 / 同手法再现 / 旧编号重现 → 信息缺口；被人盯上 → 信息缺口；凶手留下标记 → 未兑现承诺。

## 人设/金手指差异

默认金手指是观察力和信息，不是面板。高智商必须有差别：孤僻、迟钝、某种执念——千篇一律的冷静机智等于没有人。动笔前要有职业细节与动机来源，不要用档案腔开场；真凶要有迷惑性，出场就被看穿则后面没有悬念。

女频悬疑：破案为主、感情为辅，一案一结，忌油腻感情戏盖过案子；男主落地，不要完美神探飘在案上；时间诡计不熟就不要用。智斗向忌过度对称的剧本感、无废话的完美闭环、全员降智衬托；允许两边都「有道理」的对撞，但须付牺牲或代价。

## 禁止漂移

- 后期改规则、无铺垫突然知道、超自然把案子包收
- 为钩子破坏逻辑；坑开得比填得完还多；伏笔揭开时主角突然全知
- 都市或刑侦中途换国家、换地图续命
- 灵异、怪谈、悬疑爽、刑侦+通灵写成子类「刑侦探案」
- 纯话疗收真凶且无证据链

## 本类型多出来的红线

| 禁止 | 处理 |
|------|------|
| 封建迷信的做法写细 | 一笔带过，作批判或反面 |
| 冥婚、结阴亲、怀鬼胎（女频）；冰恋（男频） | 禁 |
| 真实地名、机关、领导人；影射政治；领导被超自然杀害 | 架空，不写 |
| 血腥细致、屠城、吃人、人殉 | 模糊化或禁 |
| 细写作案手法、反侦察做法 | 只写结果、痕迹、反常 |
| 凶手独立视角提前交出真相 | 限知；线索公平回看 |
| 执法体系集体作恶、抹黑公检法 | 个人可以有私心和错，体系保持正面 |
| 借悬疑写色情；非必要裸写 | 禁 |
| 重男轻女、吃绝户 | 只能当被反对的对象 |

案子要能把读者带去一个说得通的判断，不是猎奇堆砌。

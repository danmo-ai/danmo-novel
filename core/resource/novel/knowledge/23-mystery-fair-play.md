# 推理公平与线索设计

好的反转不是「作者藏了答案」，而是读者回看后能发现：答案早已出现，只是当时的解释不够完整。适用于悬疑、刑侦、权谋和含智斗的单元。

## 一、先写真相，再设计读者路径

规划时在作者侧写清：谁做了什么、为什么、何时、用什么资源、留下了什么后果。然后拆成四条链：

1. **事实链**：真实发生的事件顺序。
2. **证据链**：现场、物件、证词、记录如何证明事实。
3. **调查链**：角色按什么顺序获得并解释材料。
4. **误导链**：哪些真实细节曾被合理误读。

正文只按合同释放调查链。作者侧真相不直接进入写作或审校上下文。

## 二、线索单元格

| 字段 | 要回答的问题 |
|------|--------------|
| 首次出现 | 读者在哪一章、哪个动作里能看见它？ |
| 当时解释 | 人物和读者最初会怎样理解？ |
| 证明对象 | 它究竟证明身份、时间、动机、机会还是关系？ |
| 获取方式 | 谁凭什么能发现，是否越过权限或知情边界？ |
| 复核方式 | 另一条独立材料能否印证或反驳？ |
| 回收位置 | 哪个选择或揭示使它改变意义？ |

关键结论至少让「证据 + 排除其他解释」成立。一个重要事实可以用多种材料支持，但不要无意义重复相同线索。

## 三、公平红线

- 决定真相的证据必须在揭示前出现，不能结局临时新增。
- 假线索也必须是真实事实，只是解释有误导；伪证需要有人在戏内作假的动机与成本。
- 角色的专业知识可以提供解释，不能替代证据本身。
- 反派不能为了被抓突然降智，侦探也不能靠作者投喂灵光。
- 不用「其实还有一份没提过的监控 / 信件 / 双胞胎」补洞。
- 超自然题材先公开规则，推理仍须在规则内完成。
- 不用长篇作案教程或可操作的逃避追查细节制造专业感；写结果、痕迹与调查困境即可。

## 四、红鲱鱼怎样不浪费篇幅

一个合格的嫌疑人或假因至少承担两项功能：提供真实秘密、暴露关系、制造时间压力、推动主角选择、反衬真相。只为拖延而出现的嫌疑要删。

每个假凶可准备：他确实想隐瞒的事、他与本案的真实交集、让他显得可疑的一项证据、能排除他的独立材料、排除之后给主线带来的新增量。

排除嫌疑不应让故事归零，而应缩小可能性或暴露更深的问题。

## 五、揭示与反转

揭示前做三次回读：

1. **无答案回读**：不知道真相时，场景是否自然，而不是人人都等侦探发言？
2. **有答案回读**：知道真相后，关键行为与细节是否仍符合人物？
3. **替代解释回读**：真相是否比主要替代解释更符合全部材料？

反转后要有余波：嫌疑人关系改变、主角付出代价、旧线索重新归位。不要把全部真相压成一场无对抗的讲解。

## 六、审校问题写法

不要只报「推理不合理」，要给出能修复的证据：第几章的哪个结论缺哪条前置线索；哪个角色在此时不可能知道哪个事实；哪两个时间、位置或物件状态冲突；哪个嫌疑被排除后仍未解释其真实秘密；哪条规则在结尾被临时改变。

优先修调查链与细纲，再改正文。只把一句「他早就怀疑」插进结尾，不会补出公平性。

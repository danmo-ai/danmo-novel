# 定向修订与润色

修订的目标是用最小改动解决已指认的问题，而不是把同一篇文章换成另一种「AI 标准腔」。先修结构，再修事实，最后修句子。

## 一、先确定问题层级

| 层级 | 症状 | 应改什么 |
|------|------|----------|
| 合同 | 没有目标、冲突、选择或兑现 | 细纲，不直接堆正文 |
| 结构 | 场景顺序错、重复、高潮位置不对 | 场景与章间安排 |
| 连续性 | 时间、身份、位置、知识边界冲突 | 事实链与相关段落 |
| 人物 | 选择无动机、声音相同、高光被抢 | 行动、对白与关系 |
| 场景 | 空间模糊、无动线、无压力、无后果 | 动作与环境参与 |
| 句子 | 复读、套话、英文泄漏、冗长解释 | 局部语言 |
| 发布 | 标题、简介、标签不能兑现读者承诺 | 发布材料，不动故事事实 |

高一层没修好，不要先做低一层润色。给没有冲突的场景换更漂亮的句子，仍是空场。

## 二、修订边界

每轮写清四件事：修哪条 finding、允许改哪里、必须保留什么、怎样算修好。

- 只修被选中的 blocking 或 advisory；不因风格偏好重写无关段落。
- 保留已成立的章号、人物关系、伏笔、物件与时间，除非 finding 正是这些冲突。
- 不为润色擅自新增姓名、数字、因果、秘密或世界规则。
- 审校意见本身也可能误判；与 canon 冲突时回到事实核查。
- 局部选区编辑只替换选区，不把前后文一起改写。

## 三、定向修订配方

### 信息不足或节奏平

补一个会改变局面的动作、新证据、阻力或关系位移。不要用同义复述、天气、回忆或人物互相解释来填字数。

### 情绪直给

先保留必要的事件，再选择一个属于此人的行为后果、未完成动作或有意义的物件反应。不要机械给每个情绪句加「攥拳、咬唇、深呼吸」。

### 对话像会议纪要

确定每个人此刻想从对方那里得到什么。删已知信息复述，让答非所问、回避或条件交换产生潜台词；但无效口语不能代替推进。

### 章末口号

把「真正的危险才刚刚开始」改成一个未完成的动作、具体的新事实、迫近期限或有代价的选择。钩子必须由本章事件生长出来。

### 人设漂移

找到本场压力与人物欲望，重写关键选择或语气。不要只在旁边补一句「他本来就是这样的人」。

### 过短但完整

先确认是否完整。若完整而短，调整字数预期或合并冗余节拍；若确实欠戏，补能改变因果的场面，不做同义扩写。

## 四、去模板腔而不制造新模板

1. 先删解释已经成立画面的总结句。
2. 把抽象判断换成这个场景独有的动作、物件或数字。
3. 拉开角色句长、信息密度与回避方式，而非只换口头禅。
4. 保留有意的排比、比喻、长句和人物语域；去 AI 味不是禁词替换游戏。
5. 每轮集中修少数问题，修完通读衔接，避免局部过于工整。

## 五、验收差异

修后对比只回答：

- 被指出的证据是否消失或得到解释？
- 有没有引入新的连续性或信息边界问题？
- 不该改的事实、人物声音和好句子是否保留？
- 每处扩写删掉后是否会损失因果、人物或必要氛围？不会则删。
- 本地检查的 blocking 是否清零，剩余 advisory 是否经过判断而非照单全收？

## Checklist

- [ ] 修订层级正确，未用润色掩盖结构问题
- [ ] 修改范围、保留项与验收标准明确
- [ ] 未借润色新增事实或泄漏未来信息
- [ ] 修后衔接自然，未制造新的模板腔
- [ ] 候选经作者比较与接受后才替换正式内容
